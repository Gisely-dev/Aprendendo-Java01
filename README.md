# Java: Entendendo Variáveis

Material didático em HTML, feito para ser lido no navegador, sobre um dos conceitos mais fundamentais da programação: **variáveis**.

## Conteúdo do arquivo

[`variaveis-java.html`](./variaveis-java.html)

O material cobre:

- **O que é uma variável** — a ideia da "caixa com etiqueta" na memória do computador
- **Declarando e inicializando** — a diferença entre os dois passos e como fazê-los juntos ou separados
- **Regras e boas práticas de nomes** — o que o Java exige e a convenção camelCase
- **Tipos de dados** — `int`, `double`, `boolean`, `char` e `String`, com exemplos
- **Reatribuindo valores** — como alterar uma variável depois de criada, incluindo atalhos como `+=`
- **Constantes com `final`** — como declarar valores que nunca devem mudar
- **Erros comuns** — tabela com as mensagens de erro mais frequentes e suas causas
- **Exercícios práticos** — desafios para fixar o conteúdo

## Como usar

Basta abrir o arquivo `variaveis-java.html` diretamente no navegador. Não é necessário nenhuma instalação ou servidor.

## Sobre

Parte da série de estudo **aprendendo-java**, material criado para consolidar o aprendizado através da escrita didática.
