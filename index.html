Entendendo Variáveis em Java

Variáveis são a base de tudo em programação: é como o seu programa guarda, lembra e manipula informações. Neste guia você vai entender o que são, como criá-las e os cuidados que evitam os erros mais comuns de quem está começando.

O que é uma variável?

Imagine uma caixa com etiqueta. Você escreve um nome na etiqueta (por exemplo, "idade") e guarda um valor dentro dela (por exemplo, 25). Sempre que precisar desse valor, basta chamar a caixa pelo nome — sem precisar lembrar o valor exato o tempo todo.

Em programação, uma variável é exatamente isso: um espaço nomeado na memória do computador, usado para guardar um valor que pode ser lido e, na maioria dos casos, alterado depois.

Por que isso importa? Sem variáveis, todo programa seria fixo — sempre faria a mesma coisa, com os mesmos valores. Com variáveis, o programa pode reagir a entradas diferentes, guardar resultados de cálculos e tomar decisões.

Declarando e inicializando uma variável

Em Java, criar uma variável envolve dois conceitos que podem vir juntos ou separados:

  • Declarar — dizer ao Java o tipo e o nome da variável.
  • Inicializar — dar um valor inicial a ela.
// Declarando e inicializando na mesma linha
int idade = 25;

// Declarando primeiro, inicializando depois
int idade;
idade = 25;

A estrutura geral é sempre: tipo nome = valor; — não esqueça do ponto e vírgula no final, ele marca o fim do comando.

Atenção: se você declarar uma variável sem inicializá-la e tentar usá-la antes de dar um valor, o Java vai recusar a compilar o programa, com o erro variable might not have been initialized.

Regras e boas práticas para nomear variáveis

Nem todo nome é válido, e nem todo nome válido é uma boa escolha. Regras obrigatórias do Java:

  • Pode conter letras, números, _ e $, mas não pode começar com número.
  • Não pode ser uma palavra reservada da linguagem, como class, int ou public.
  • É case-sensitive: idade e Idade são variáveis diferentes.

Além das regras obrigatórias, existe uma convenção que todo programador Java segue — o camelCase: a primeira palavra em minúsculas, e cada palavra seguinte começando com maiúscula.

O tipo define o que a variável pode guardar

Diferente de linguagens como Python, em Java você precisa avisar o tipo de dado logo na declaração — isso se chama tipagem estática. Uma vez definido, o tipo não muda.

Repare nas aspas: texto (String) usa aspas duplas "assim", enquanto um único caractere (char) usa aspas simples 'assim'. Trocar uma pela outra gera erro de compilação.

Tentar guardar um valor do tipo errado numa variável também gera erro. Por exemplo, isto não compila:

int idade = "vinte e cinco"; // erro: String não é int

Reatribuindo valores

Depois de criada, uma variável comum pode receber um novo valor a qualquer momento — desde que seja do mesmo tipo:

int pontuacao = 0;
System.out.println(pontuacao); // 0

pontuacao = 10;
System.out.println(pontuacao); // 10

pontuacao = pontuacao + 5;
System.out.println(pontuacao); // 15

Repare na última linha: pontuacao = pontuacao + 5; pega o valor atual da variável, soma 5, e guarda o resultado de volta na mesma variável. Isso é extremamente comum em programação — tão comum que Java tem um atalho:

pontuacao += 5; // mesmo efeito de "pontuacao = pontuacao + 5"

Esse atalho também existe para as outras operações: -=, *=, /=.

Quando o valor não deve mudar: final

Às vezes você quer garantir que um valor nunca seja alterado depois de definido — por exemplo, o valor de um imposto fixo ou o número de dias da semana. Para isso, usamos a palavra-chave final:

final int DIAS_DA_SEMANA = 7;

Se você tentar mudar o valor depois, o Java recusa a compilar:

DIAS_DA_SEMANA = 10; // erro: cannot assign a value to final variable
Convenção: constantes (variáveis final) costumam ser escritas em MAIÚSCULAS, com underline separando as palavras — isso ajuda a identificá-las rapidamente no meio do código.
